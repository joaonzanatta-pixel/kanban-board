# kanban-board
I developed an interactive and fully functional Kanban Board focused on user experience and personal productivity. The main goal of this project was to apply advanced DOM manipulation concepts and modern JavaScript (ES6+) event handling.  

Dynamic Interface (Drag and Drop): Native implementation of drag-and-drop events, allowing users to seamlessly move task cards between "To do", "In progress", and "Done" columns.Semantic Structure & Layout: Built a clean and organized UI using Semantic HTML5 and modern CSS (Flexbox/Grid), ensuring proper visual alignment of components and active card states.  Clean Code Practices: Organized the JavaScript script into well-defined, reusable functions, prioritizing code readability and optimized task rendering performance.
